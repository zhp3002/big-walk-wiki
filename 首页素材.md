3、网站主题色

我建议：默认亮色主题。

Big Walk 官方视觉不是传统游戏 Wiki 那种黑色/暗紫，而是非常明显的自然、户外、草地、天空、探索感。因此建议主色采用偏自然的草绿色。
/* 导航页主题色 - 亮色主题 */
--nav-theme: 106 35% 42%;       /* natural green */
--nav-theme-light: 106 35% 55%; /* light green */

/* 导航页主题色 - 暗色主题 */
--nav-theme: 106 32% 48%;       /* natural green */
--nav-theme-light: 106 32% 60%; /* light green */
